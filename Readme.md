# C. Answer in Brief

### 1. Define word processing software.

**Word processing software** is a computer program used to create, edit,
format, save and print text documents.

### 2. How do you create a new document in Writer?

1.  Click the **File** menu.
2.  Click **New**.
3.  Select **Text Document**.
4.  A new Writer document will open.

### 3. Define views in Writer.

**Views** are different ways of displaying a document on the screen,
such as Print Layout View, Web Layout View and Full Screen Document
View.

### 4. How do you save a document in Writer?

1.  Click **File → Save**.
2.  Enter the document name.
3.  Select the location.
4.  Click **Save**.

**Shortcut:** `Ctrl + S`

### 5. Write the names of the components of a word processing window.

Important components include:

-   Title Bar
-   Menu Bar
-   Toolbars
-   Ruler
-   Document/Work Area
-   Scroll Bars
-   Status Bar

### 6. Write the steps to change the document view.

1.  Open the **View** menu.
2.  Select the required view, such as **Print Layout**, **Web Layout**
    or **Full Screen**.
3.  The document will be displayed in the selected view.

# D. Answer in Detail

### 1. Write any five features of a word processor.

Five features are:

1.  **Creating documents** -- We can create new text documents.
2.  **Editing text** -- We can insert, delete, copy and move text.
3.  **Formatting text** -- We can change font, size, colour, alignment,
    etc.
4.  **Spell checking** -- It helps identify spelling mistakes.
5.  **Printing documents** -- We can print the document on paper.

Other features include inserting pictures and tables, finding and
replacing text, saving documents and undo/redo.

### 2. What are the applications of a word processor?

A word processor can be used to:

-   Write letters and applications.
-   Prepare reports and projects.
-   Create notices and circulars.
-   Prepare resumes and forms.
-   Create school assignments and question papers.
-   Edit and format documents.
-   Create tables and lists.
-   Print documents.

### 3. How to insert text in a Writer document? Write steps.

1.  Open **LibreOffice Writer**.
2.  Click at the required position in the document.
3.  The **insertion point/cursor** appears there.
4.  Type the required text using the keyboard.
5.  The text will appear at the cursor position.

### 4. How to open an existing document? Write steps.

1.  Click the **File** tab/menu.
2.  Click **Open**.
3.  An **Open** dialog box appears.
4.  Select the required file.
5.  Click the **Open** button.
6.  The selected document will open.

**Shortcut:** `Ctrl + O`

### 5. How many ways are there to view a document in Writer? Write about them.

According to this chapter, there are **three ways** to view a document:

1.  **Print Layout View**\
    It displays the document as it will appear when printed.

2.  **Web Layout View**\
    It displays the document in a format suitable for viewing as a web
    page.

3.  **Full Screen Document View**\
    It displays the document using the full screen, providing more space
    for viewing the document. Press **Esc** to exit Full Screen mode.
