# C. Answer in Brief

### 1. Define word processing software.

**Answer:**  
Word processing software is application software used to create, edit, format, save and print text documents.

### 2. How do you create a new document in Writer?

**Answer:**  
To create a new document in Writer:

1. Click on the **File** menu.
2. Select **New**.
3. Click on **Text Document**.
4. A new document opens in Writer.

### 3. Define views in Writer.

**Answer:**  
Views are different ways of displaying a document in the Writer window. Writer provides different views such as **Print Layout View, Web Layout View and Full Screen Document View**.

### 4. How do you save a document in Writer?

**Answer:**  
To save a document:

1. Click on the **File** menu.
2. Select **Save**.
3. Enter the file name and select the location.
4. Click on the **Save** button.

**Shortcut key: Ctrl + S**

### 5. Write the name of the components of a word processing window.

**Answer:**  
The main components of a word processing window are:

1. Title Bar
2. Menu Bar
3. Toolbars
4. Ruler
5. Document Area
6. Scroll Bars
7. Status Bar

### 6. Write the steps to change the document view.

**Answer:**  

1. Click on the **View** menu.
2. Select the required view.
3. Choose **Print Layout**, **Web Layout** or **Full Screen** as required.

# D. Answer in Detail

### 1. Write any five features of word processor.

**Answer:**  
Five features of a word processor are:

1. **Creating documents:** It allows us to create new documents.
2. **Editing text:** We can insert, delete, copy and move text.
3. **Formatting text:** We can change the font, size, style, colour and alignment of text.
4. **Spell checking:** It helps us to find and correct spelling mistakes.
5. **Printing:** It allows us to print documents on paper.

### 2. What are the applications of word processor?

**Answer:**  
A word processor can be used for:

1. Creating letters and applications.
2. Preparing reports and projects.
3. Creating notices and circulars.
4. Preparing resumes and forms.
5. Preparing school assignments and question papers.
6. Creating and editing documents.
7. Creating tables and lists.
8. Printing documents.

### 3. How to insert text in Writer document? Write steps.

**Answer:**  
To insert text in a Writer document:

1. Open **LibreOffice Writer**.
2. Place the cursor at the required position in the document.
3. Type the required text using the keyboard.
4. The typed text appears at the cursor position.

### 4. How to open an existing document? Write steps.

**Answer:**  
To open an existing document:

1. Click on the **File** menu.
2. Click on the **Open** option.
3. An **Open** dialog box appears.
4. Select the required file.
5. Click on the **Open** button.
6. The selected document will open in Writer.

**Shortcut key: Ctrl + O**

### 5. How many ways are there to view a document in Writer? Write about them.

**Answer:**  
There are **three ways** to view a document in Writer:

1. **Print Layout View:**  
   It displays the document in the same way as it will appear when printed. It is the **default view** in Writer.

2. **Web Layout View:**  
   It displays the document in a way similar to how it would appear as a web page.

3. **Full Screen Document View:**  
   It displays the document using the full screen. This provides more space for viewing the document. The **Esc key** can be used to exit Full Screen mode.
